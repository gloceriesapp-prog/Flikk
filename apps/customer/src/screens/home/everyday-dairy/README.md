# Everyday Dairy

Home’s All tab shows this section where admin's Home Sections places it (seeded just before Nearby Stores by migration 116); admin can hide or reorder it. Only a server without the row falls back to that default position. The default title is Everyday Dairy.

Milk, curd, paneer, butter/ghee, cheese and buttermilk/lassi/cream are selected from nearby shops. The shared collection component balances product types and renders existing product cards in a horizontal row with address, loading, retry and empty states. No sample stock is inserted. Name matching excludes common plant alternatives and personal-care terms; structured catalogue tags can replace these rules later.
